# شناخت بازیکن (Football Player Quiz)

بازی فارسی و **کاملاً آفلاین** حدس بازیکن فوتبال.

## ویژگی‌ها
- صفحه اصلی با پس‌زمینه کامل تصویر منو (تمام صفحه گوشی)
- صفحه سؤال با طراحی مدرن (تایمر، سکه، راهنمایی، فریم طلایی)
- ۲۴ بازیکن معروف
- ذخیره پیشرفت و سکه با LocalStorage
- مناسب موبایل (RTL، safe-area، بدون اسکرول اضافه)
- بدون نیاز به اینترنت یا فونت خارجی

## اجرا
1. فایل‌ها را روی گوشی یا کامپیوتر کپی کن.
2. با یک وب‌سرور ساده باز کن (چون فایل‌های محلی گاهی محدودیت CORS دارند):
   - اگر Node داری: `npx serve .`
   - یا با Python: `python -m http.server 8080`
3. یا روی GitHub Pages منتشر کن.

## ساختار
```
football-player-quiz/
├── index.html          # صفحه اصلی (منو)
├── game.html           # صفحه بازی
├── css/style.css
├── js/home.js
├── js/game.js
├── assets/images/entry-screen.webp
└── players/*.png       # تصاویر بازیکنان
```

## کنترل‌ها
- **شروع بازی**: شروع از مرحله فعلی
- **لیست مراحل**: انتخاب مرحله باز شده
- **جوایز روزانه**: +۱۵۰ سکه یک‌بار در روز
- در بازی: راهنمایی ۵۰ سکه (حذف دو گزینه اشتباه)

ساخته‌شده برای تجربه روان و زیبا روی گوشی.
